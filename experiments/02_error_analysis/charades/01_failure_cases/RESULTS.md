# Charades 定位失败案例与帧证据 · 结果摘要

整理于 2026-11-06；历史数值来自本目录轻量报告，不重新执行模型。

## 检查方法

仅用 CPU，从实际 processor patch tensor 逆变换重建可见帧，核对往返数值一致、时间标签、GT 和预测边界。保留原查询和正式 GT，不把独立挑选的失败案例视作随机总体。

第一组包含 6 个固定诊断/对照案例；时间轴全量后追加原先失败的 **2233/V6H2O 与 81/EYZXC**，排查时间轴之外的问题。

## 主要观察

- 2233：源时间轴下仍把后续拿杯/电话场景定位成喝水；可见饮水动作更早。支持继续查动作与上下文绑定，尚不能证明具体注意力机制是根因。
- 81：FIG 强调倒水，继承的 GT 对应坐到桌边；原视频另一条粗描述才是倒水，其时间范围不同。倒水与坐下部分重叠，不能声称 GT 内完全没有倒水。
- 两题均在首轮接受正确视频，未触发 SQR。它们不能单靠增加查询更新轮数解决。
