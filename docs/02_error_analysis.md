# 02 · 复现后的错题与数据分析

重点是“正确视频上的起止时间为什么不准”，依次区分时间标签、动作识别/边界判断、标注范围及评测口径。

| 分析 | 内容与结论 | 记录 |
| --- | --- | --- |
| 实际输入重建 | 从 processor patch 逆变换重建帧，比较 GT、预测和模型时间标签；先看 6 个诊断/对照，再看 2233 与 81 | [失败案例](../experiments/02_error_analysis/charades/01_failure_cases/RESULTS.md) |
| 时间标签问题 | 同一批像素的名义时间与源采样时间可能不同；对照实验已单列到优化阶段 | [阶段 03](03_optimization.md) |
| 2233/V6H2O | 源时间轴下仍将较晚的场景定位为饮水，支持查动作/上下文绑定，尚不能证明内部机制 | [案例目录](../experiments/02_error_analysis/charades/01_failure_cases/README.md) |
| 81/EYZXC | FIG 强调倒水却继承坐下事件范围，二者部分重叠；不能把全部偏差归因于模型 | [标注审计](../experiments/02_error_analysis/charades/02_annotation_audit/RESULTS.md) |

扩大标注审计后：随机 100 条文本复核有 86 条同目标、11 条相关动作/边界风险、2 条疑似动作改变、1 条措辞歧义。定向风险样本不用于估计总体错误率；画面支持部分动作阶段/方向反转，也有兼容连续动作或原粗标注可疑的情况。

543 条 GT 末端超出声明时长属于结构风险，不等于 543 条语义错标。按现有预测裁剪规则，15 条理论最大 IoU 小于 0.7，低于 0.5/0.3 的均为 0 条。正式 GT、查询和完整测试分母均保留。

这些是定位优化的背景证据，不直接当作新方法的独立训练/留出集。后续新增计分、标注、输入分析放本阶段；实际改动后跑模型的比较放阶段 03。
