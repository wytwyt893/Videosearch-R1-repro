# ActivityNet-FIG 数据审计与原视频修复 · 结果摘要

整理于 2026-11-06；历史数值来自本目录轻量报告，不重新执行模型。

## 数据问题与修复

完整候选库 **4866 个视频**，完整测试 **16966 题**。发布张量中有 **364 个疑似采样异常视频**。元数据记录的源时间覆盖较长，但部分像素序列疑似只有开头帧。

流程依次为：审计 NPY 与源元数据 → 找到可公开获取的原视频 → 检查时长和画面对应 → 解码获取真实总帧数 → 按覆盖全片的采样索引导出 → 保存来源、原/新索引及哈希 → 构建修复数据视图并做完整性检查。

364 个目标均形成已验收修复；镜像源文件不声称与作者原始视频逐字节相同。原发布像素、检索向量和正式 GT 均保留，修复像素位于根目录 `data/activitynet_repair_v1/`。

## 产物和限制

- `reports/27*`—`30*`：时间元数据、采样覆盖、首个原视频对应示例。
- `reports/31*`—`34*`：修复集合、来源复核、CPU 预检、完整性和标注观察。
- `outputs/`：原视频对应示例、复核数组和截图、完整性扫描结果。
- 两份候选 NPY 已确认与正式修复 NPY 的 SHA256 相同，改为链接；两份复核 NPZ 只做无损压缩，数组逐元素相等。详情见实验 00 的迁移清单。

修复数据不等于已经证明模型得分提升；需要相同配置下原版/修复版配对实验才能归因。全量结果另见实验 04。
