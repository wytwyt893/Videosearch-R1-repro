# Charades 二次定位与证据提示小实验 · 结果摘要

整理于 2026-11-06；历史数值来自本目录轻量报告，不重新执行模型。

## 问题和设计

2026-11-06，测试“已经检索到正确视频时，再要求核对动作证据是否能改善时间边界”。**这是训练来源的条件定位小实验，不是完整 T=2/N=8 VCMR，也不是未见视频泛化测试。** 发布 Stage2 权重可能已训练过这些视频。

冻结的 35 个 QA 来自训练集，开发组 12、视频不重叠留出组 23；选入前要求初始检索 top1 正确，并做粗细描述质量筛查，排除 1 条明显风险样本后不补抽。正式 test 标签未用于选样或调整提示词。

| 条件 | 操作 |
| --- | --- |
| A 原始定位 | 官方提示词与源时间轴 |
| B 普通二次判断 | 在相同视频上再判断一次，可调整 A 的起止位置 |
| C 证据提示二次判断 | 相同额外调用上限，要求核对实际动作与邻近时间证据 |

只有 A 接受且有有效区间时才执行 B/C；后续回答无效、不匹配或截断就回退 A。A 不接受的题仍留在分母。固定权重、像素、帧数、视觉预算、源时间标签；冻结初始验证和排名，不执行 SQR。B/C 最多各多 1 次调用、输出上限相同，实际文本 token 和耗时分别计入。

## 结果

| 23 题留出组 | mIoU | IoU≥0.3 | IoU≥0.5 | IoU≥0.7 |
| --- | ---: | ---: | ---: | ---: |
| A 原始定位 | 51.47% | 16/23 | 14/23 | 8/23 |
| B 普通二次判断 | 51.30% | 16/23 | 14/23 | 8/23 |
| C 证据提示 | 52.23% | 16/23 | 14/23 | 9/23 |

C 相对 B 的平均 IoU 增量为 **0.00931**，配对 bootstrap 95% 区间 **[0, 0.02385]**，包含 0；仅多 1 个 IoU≥0.7 命中。12 题开发组 C 略降，不能据此宣布稳定改进，也没有自动启动全量测试。

共 35 条完整配对记录、89 次实际生成调用（35+27+27）。留出组 C 的 20 次额外调用中有 17 次有效区间与 A 相同；对输出中额外非边界时间标签的启发式检查均为 0，但这不证明模型未看像素，也不等价于解释真实性判定。

## 成本、故障和后续

单卡 GPU1，约 **250.95 秒**，设备显存采样峰值 **36771 MiB**，完成后 GPU 已释放。首次尝试在加载权重前因 Torch UUID 类型处理失败；修复后重新 CPU 验收并使用独立目录运行，故障日志和旧验收单保留。

留出组 11823 的区间由 11–18 秒变为 10–18 秒，越过 IoU@0.7 阈值；单例边界移动不能证明模型获得新的动作理解能力。下一步候选是实际候选片段比较，先在开发数据上验证，而非继续堆叠同一类提示词。
